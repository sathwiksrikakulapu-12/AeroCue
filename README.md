# AeroCue

Autonomous Drone Swarm for Disaster Search & Rescue.

## Project Structure

- src/ - ROS 2 swarm architecture and AI nodes
- gcs/ - Ground Control Station
- escue/ - Rescue Field Terminal
- mesh/ - Drone-to-drone mesh communication simulation
- docs/ - Project documentation

## System Workflow

Drone Swarm ? AI Detection ? GPS Tagging ? Mesh Relay ? GCS ? Rescue Coordination

## Components

### ROS 2
- Mission Planner
- Drone Controller
- Drone Simulator
- Swarm Synchronization
- AeroCue AI

### Ground Control Station
- Mission planning
- Live drone map
- Telemetry
- Video feed
- AI detection
- GPS relay visualization

### Rescue Field Terminal
- Survivor GPS
- Rescue team GPS
- Route to survivor
- Map navigation
- Voice guidance
- GCS communication

### Mesh
- Drone-to-drone communication
- GPS packet relay
- GCS communication simulation
